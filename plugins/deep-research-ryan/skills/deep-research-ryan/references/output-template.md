### v2 強制：每個資料點 4 項標註

報告中任何具體事實/數字/結論的格式：

`{斷言內容} {信心符號} {L 級} {URL/出處} {日期}`

範例：
- ✅ `[公司] Q1 2026 GAAP 淨利率 53% 🟢 L1 https://sec.gov/...10Q 2026-04-15`
- ✅ `Counter-positioning 評估強 🟡 L2 (基於 [公司] 法說對競品競爭表態 + Hamilton Helmer 7 Powers 框架)`
- ❌ 缺評級：`[公司] 估值很高`
- ❌ 缺 URL：`Q1 2026 收入 $1.63B 🟢 L1`
- ❌ 缺日期：`Q1 2026 收入 $1.63B 🟢 L1 sec.gov`

QG 第 1 層會掃描報告統計漏附比例。

## 決策建議

> 這是報告的核心價值所在。給出明確建議，不要模糊帶過。

### 綜合結論（5 級評分）

**一句話評估**：[評級]——[核心理由]

| 評級 | 含義 | 適用情境 |
|------|------|---------|
| ⭐⭐⭐⭐⭐ 強烈推薦 | 機會明確、風險可控、時機良好 | 多數關鍵指標正面 |
| ⭐⭐⭐⭐ 推薦 | 整體正面，有少數注意事項 | 正面因素顯著多於負面 |
| ⭐⭐⭐ 中性/需觀察 | 機會與風險並存，需更多資訊 | 正負因素大致平衡 |
| ⭐⭐ 謹慎 | 風險顯著，需充分準備再行動 | 負面因素多於正面 |
| ⭐ 不推薦 | 風險過高或時機不對 | 多數關鍵指標負面 |

## 關鍵缺失信息與影響評估

> 明確告知用戶報告的邊界在哪裡，哪些結論因信息缺失而需謹慎對待。

| 缺失信息 | 原因 | 對結論的影響 | 建議取得方式 |
|---------|------|------------|------------|
| [例：未上市公司無公開財報] | 非公開公司 | 財務評估依賴推估值，不確定性高 | 直接聯繫公司 / 行業專家訪談 |
| [例：核心技術細節未公開] | 商業機密 | 技術壁壘評估可能偏樂觀 | 諮詢該領域工程師 / 反向工程分析 |
| [例：用戶留存數據] | 非公開指標 | Unit Economics 為推估，實際可能有顯著偏差 | 要求公司提供 / 參考同業基準 |

**整體影響評估**：[1-2 句總結——缺失信息是否足以動搖核心結論？哪些決策建議因此需要額外謹慎？]

## 報告中的符號說明

### 信心評級（資料可靠度）

| 符號 | 含義 | 你該怎麼對待 |
|------|------|------------|
| 🟢 已驗證 | ≥2 個獨立來源交叉確認 | 可以放心引用 |
| 🟡 單一來源 | 只有 1 個來源，但來源可靠 | 大致可信，重大決策建議再確認 |
| ⚠️ 推估值 | 基於間接資料推算 | 參考用，不宜作為決策唯一依據 |
| ⬜ 無資料 | 搜索後未找到 | 此領域是盲區，需自行補充 |
| ❗ 爭議未解 | 不同來源說法矛盾 | 報告中會列出各方說法，你需要自行判斷 |

### 決策評分

| 評級 | 含義 |
|------|------|
| ⭐⭐⭐⭐⭐ 強烈推薦 | 機會明確、風險可控、時機良好 |
| ⭐⭐⭐⭐ 推薦 | 整體正面，有少數注意事項 |
| ⭐⭐⭐ 中性/需觀察 | 機會與風險並存，需更多資訊 |
| ⭐⭐ 謹慎 | 風險顯著，需充分準備再行動 |
| ⭐ 不推薦 | 風險過高或時機不對 |

### 供應商/方案優先度

| 符號 | 含義 |
|------|------|
| 🔴 立即聯繫 | 高優先，建議儘快接洽 |
| 🟡 短期評估 | 1-3 個月內評估 |
| 🟢 中期觀望 | 持續關注，暫不行動 |
| ⚪ 備選 | 記錄備用，需要時再啟動 |

### 假設穩固度（Devil's Advocate 分析）

| 符號 | 含義 |
|------|------|
| 🟢 高 | 假設有充分證據支持 |
| 🟡 中 | 有支持但也有合理質疑 |
| 🔴 低 | 假設脆弱，結論需謹慎對待 |
