# Subagent 配置規範、Rate Limit 與 MANIFEST 格式

## 1. 工具分配策略

工具分配策略：偶數 subagent（P1-A, P1-C）主力使用 Exa，奇數 subagent（P1-B, P1-D）主力使用 WebSearch。若工具回傳 429 錯誤，切換到備援工具。

---

## 2. 重試邏輯（所有 Subagent 必須遵守）

```
工具呼叫失敗時：
  嘗試 1 → 失敗 → 短暫等待後重試
  嘗試 2 → 失敗 → 等待後重試
  嘗試 3 → 失敗 → 執行降級策略：
    - 若是 Exa 失敗 → 改用 WebSearch
    - 若是 WebFetch 失敗（403/429）→ 嘗試使用 r.jina.ai/{URL} 重新抓取，失敗則跳過該來源
    - 若是 WebSearch 失敗 → 改用 web_search_exa
    - 在輸出中記錄錯誤（工具名稱、錯誤類型、影響的維度）
    - 繼續其他維度，不得空回應或中止
```

**禁止**靜默跳過失敗（因為缺失的錯誤記錄會讓 Gap Analysis 無法正確識別資料缺口）、返回空結果（因為空結果會被主 agent 誤判為「該維度無資料」而跳過補查）、不記錄錯誤（因為無法追溯哪些維度需要在 Phase 2 補強）。

---

## 3. Subagent 輸出規範

### 每個資料點的格式（所有 subagent 必須遵守）

```markdown
**[資料內容描述]**：[具體數據或資訊]
- 來源 1：[工具名稱] → [URL]（採集日期：YYYY-MM-DD）
- 來源 2：[工具名稱] → [URL]（採集日期：YYYY-MM-DD）
- 信心評級：🟢 已驗證（2+來源一致）/ 🟡 單一來源 / 🔴 待驗證 / ⚠️ 推估值
```

### 寫入要求

subagent 完成所有負責維度的搜索後，一次性寫入輸出檔案。

### 陌生詞標記

subagent 在搜索過程中遇到未能充分解釋的專有名詞，在輸出末尾附加：
```markdown
---
## 待主對話跟進的陌生詞
- [詞語1]：出現於 [脈絡]，未找到充分解釋
- [詞語2]：出現於 [脈絡]，需進一步查詢
```

## 5. Subagent Prompt 模板

啟動每個 Phase 1 / Phase 2 的 subagent 時，prompt 必須包含以下結構：

```
你是深度研究 subagent，負責以下任務。

【研究主題】：{主題}
【負責維度】：{維度清單}
【輸出路徑】：{輸出目錄}/{檔名}_{YYYYMMDD}.md
【主力工具】：{Exa 或 WebSearch}（見下方工具分配）

【多語言查詢規則】
- 英文（必查）：任何主題都必須包含英文查詢
- 台灣公司/市場/議題 → 加繁體中文
- 中國大陸公司/市場 → 加簡體中文
- 日本公司/技術 → 加日文（用日文公司名）
- 韓國公司/技術 → 加韓文（用韓文名）
- 全球產業/市場 → 英文 + 繁中 + 簡中
- 中文資料不足時立即切換英文補查

【語意擴展】
不只使用字面關鍵字，必須自動擴展：
- 正式名稱變體：縮寫、別名、前公司名（如 Meta → Facebook）
- 相關概念：描述同一事物的不同說法
- 上下游關聯：競爭對手、母子公司、主要產品名
- 問題導向：用戶真正想知道的事

【社交平台搜索】（不可省略）
- Reddit: site:reddit.com {主題}
- Glassdoor: {公司名} Glassdoor review
- Hacker News: site:news.ycombinator.com {主題}
- 台灣主題必查：PTT (site:ptt.cc)、Dcard (site:dcard.tw)、Facebook
- 中國主題可查：知乎、微博、小紅書

【工具分配與優先級】
- 偶數 subagent（P1-A, P1-C）主力使用 Exa（web_search_exa / company_research_exa）
- 奇數 subagent（P1-B, P1-D）主力使用 WebSearch
- 每個維度仍需至少 2 種不同工具交叉驗證
- WebFetch 用於抓取具體頁面
- 若主力工具回傳 429 錯誤 → 切換到備援工具
- 若 WebFetch 回傳 403/429/503 → 嘗試 https://r.jina.ai/{原始URL}，失敗則跳過並標記

【必要行為】
1. 每個維度至少使用 2 種不同工具查詢（互相驗證）
2. 每個資料點附來源 URL + 工具名稱 + 日期
3. 工具失敗時重試最多 3 次，失敗後降級到備援工具，記錄錯誤
4. 在輸出末尾列出陌生詞清單
5. 任務完成後返回一行摘要：
   「P{N}-{字母} 完成：{X} 個維度，發現 {Y} 個待跟進陌生詞，輸出寫入 {路徑}」

【待研究的維度】：
{逐條列出維度及說明}
```
