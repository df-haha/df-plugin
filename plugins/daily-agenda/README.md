# daily-agenda — 每日待辦與行程彙整

> ⚠️ 測試中版本（0.0.3-dev）：完整流程尚未在 Windows 上驗證完畢，請先不要推廣給同事。

每天一個指令 `/agenda`，一次讀取你的 **Outlook 信件、Outlook 行事曆、LINE 電腦版對話**，依照你個人的「判斷準則」整理出：

- **今天要處理**：新的與延續中的待辦（P0／P1／P2、期限、來源、已延續幾天）
- **可能已完成**：AI 判斷可能做完的項目，你確認後才移除
- **行程**：今天與未來 3 天
- **已略過**：依準則略過的內容，讓你知道 AI 沒看漏

昨天沒做完的待辦不會因為換日消失；你說「R-7K2 的 3、5 做完了」就會更新。

需要回 LINE 或建立行事曆事件時，AI 先擬稿，**每一次都由你本人在確認視窗中看完完整內容、按允許後才會送出**。

## 使用前請先知道

**資料會送到雲端分析。** 信件、行事曆、LINE 的內容（包含客戶名稱與業務內容）會原樣交給 Claude 分析，不做遮蔽。設定時你也可以提供個人文件（簡報、績效資料等），這些檔案同樣會送給 Claude 分析，用來建立你的工作檔案（profile），讓判斷更準確。你可以在設定時選擇不讀某些 LINE 對話（例如家人群組），被排除的對話完全不會被讀取。請依公司使用的 Claude 方案條款確認可否這樣使用。

**Outlook 權限。** 本工具透過 `df-graph` plugin 讀取 Outlook。df-graph 登入時取得的權限包含讀信、寄信、修改行事曆（Mail.ReadWrite、Mail.Send、Calendars.ReadWrite），大於讀取所需；本工具平常只讀取，只有在你確認後才會建立行事曆事件。

**公司端點防護。** 讀取 LINE 電腦版資料需要讀取 LINE 程式的記憶體（取得解密金鑰），這個行為可能觸發公司的防毒或端點防護告警。部署前請先請 IT 確認。

## 需求

- Windows（x64）上的 Claude Code（原生版，不支援 WSL 或 macOS）
- Node.js 24 以上、[uv](https://docs.astral.sh/uv/)
- LINE 電腦版已登入並開著視窗（縮到右下角時可能讀不到）
- 已安裝並登入 `df-graph` plugin（`/df-graph-setup`）

## 開始使用

1. 安裝 `df-graph` 與 `daily-agenda` plugin。
2. 執行 `/agenda-setup`，跟著問答完成設定（大約 10 分鐘；第一次會下載約 100MB 的執行元件）：
   同意說明 → 環境檢查 → LINE 試讀 → 自動找到你的 LINE 帳號資料 → 串 Outlook → 選擇不讀的 LINE 對話 → 選擇信箱資料夾 → 個人資料夾（可跳過）→ 輸出格式、位置與排程 → 掃描過去 7／14／30 天建立判斷準則。
3. 之後每天執行 `/agenda`。

## 常用說法

| 你說 | 會發生什麼 |
|---|---|
| `/agenda` | 產生今天的彙整檔 |
| 「R-7K2 的 3、5 做完了」 | 把那份彙整的第 3、5 項標成完成 |
| 「T-4821 做完了」／「T-4821 不用追了」 | 依待辦代碼標記 |
| 「恢復 T-4821」 | 把摺疊起來的項目移回待辦 |
| 「修正判斷準則」 | 調整 AI 的判斷規則（每次修改都保留舊版） |
| `/agenda-reply` | 擬稿回 LINE，確認後送出；內容有時間時詢問是否建立行事曆事件 |
| `/agenda-setup` | 修改排除的對話、信箱資料夾、輸出位置、排程，或解除安裝 |
| 「換成 Opus」／「用 Sonnet 就好」 | 更換整理訊息用的 AI 模型（預設 Sonnet：快、便宜、分類整理夠用） |

## 隱私與安全設計

- 負責閱讀信件與 LINE 內容的 AI 是一個**沒有任何工具**的獨立程序：它只能回傳整理結果，就算訊息裡夾帶「幫我送訊息給某人」之類的文字，也沒有能力執行。
- AI 整理出的每一項都必須對應到真實存在的來源；對應不到的結果會被丟棄。
- 送出 LINE 與建立行事曆只能經過本工具的確認流程：你確認的內容與實際送出的內容必須完全一致，確認只能用一次、10 分鐘內有效。送出結果不確定時只查詢是否已送達，不會自動重送。
- 本工具不會把 LINE 註冊成 Claude 的常駐工具；沒有啟用本工具時，不存在任何送出 LINE 的途徑。
- **對話鎖定**：當 AI 讀取了外部訊息的原文（例如查看 LINE 對話清單或 Outlook 預覽），該對話會被自動鎖定——只能繼續使用 daily-agenda 的功能，不能寄信、上網或執行其他指令。這是為了防止訊息中夾帶的惡意指令被 AI 執行。要做其他事，只需開一個新對話。
- 你的設定與紀錄存在 `%USERPROFILE%\.daily-agenda\`，只在你的電腦上。其中 `runs\` 存每次掃描到的原始內容（信件、LINE 訊息原樣，包含訊息裡出現的密碼或驗證碼），`history.sqlite` 只存 AI 整理後的摘要；兩者都只有你的 Windows 帳號能讀。

## 解除安裝

執行 `/agenda-setup` 並選「解除安裝」：會移除排程，並詢問是否刪除 `%USERPROFILE%\.daily-agenda\`。你的彙整檔不會被刪除。之後再從 Claude Code 移除 plugin 即可。
