# Subagent 配置與工作規範

## 5 種專項 Agent

| Agent | 角色 | 驗證對象 | 主要搜尋來源 |
|-------|------|---------|-------------|
| Agent 1 🏢 | 實體查核 | 公司/組織/品牌 | 官網、LinkedIn、Crunchbase、新聞 |
| Agent 2 ⚙️ | 技術查核（重點） | 技術/框架/演算法/工具 | 官方文檔、GitHub、技術論文 |
| Agent 3 📊 | 數據查核 | 統計數據、市場規模、財務 | 產業報告、財報、官方統計 |
| Agent 4 👤 | 人物查核 | CEO/創辦人/專家 | LinkedIn、個人網站、新聞 |
| Agent 5 💡 | 論述查核 | 商業模式、市場分析、趨勢 | 產業報告、競爭分析、專家評論 |

## 每個 Agent 的工作流程

```
1. 接收驗證項目清單（含原文位置標記）
2. 對每項執行 5 層查證（依據 prompt 中嵌入的 checklist）
3. WebSearch 至少 3 個獨立來源交叉驗證（因為不同搜尋引擎常引用同一底層來源，3 個來源增加命中獨立來源的機率）
4. 將完整結果用 Write 工具寫入臨時檔案
5. 只返回一行摘要給主 agent
```

## 結果輸出規範（關鍵！）

### Subagent 必須將結果寫入檔案

```
輸出路徑：{輸出目錄}/
檔案命名（優先 .md，若被 hook 阻擋則改用 .txt）：
  - agent-1-entity.md    （實體查核結果）
  - agent-2-tech.md      （技術查核結果）
  - agent-3-data.md      （數據查核結果）
  - agent-4-people.md    （人物查核結果）
  - agent-5-argument.md  （論述查核結果）
```

### 每個結果檔案的格式

```markdown
# [Agent 類型] 查核結果

**驗證項目數**：X 項
**致命錯誤**：X 項
**嚴重錯誤**：X 項
**中度問題**：X 項
**無法查證**：X 項
**正確但缺來源**：X 項

---

## 項目 1：[項目名稱]

📍 位置：[第X章 > 第Y段]
📝 原文：> 「...」
結果：🚨/⚠️/📊/💡/✅/⬜（⬜ = 無法查證 UNVERIFIED，非錯誤，獨立計數）
問題：[描述]
正確資訊：[查證結果]
無法查證：N 項（證據欄附工具/錯誤原因/重試次數/替代搜索結果）
來源：
- [L1] [來源1](URL)
- [L2-L3] [來源2](URL)
- [L4] [來源3](URL)

(重複以上格式)
```

### 返回給主 Agent 的摘要（僅此一行）

```
[Agent類型]查核完成：X項驗證，Y項致命/Z項嚴重/W項中度/V項無法查證，結果已寫入 {輸出目錄}/agent-N-[type].md
```

## 智能分批策略

| 項目數 | 批次數 | 每批次 agents |
|--------|--------|--------------|
| ≤ 20 | 1 批 | 5 個 |
| 20-50 | 2-3 批 | 每批 5 個 |
| 50-100 | 3-5 批 | 每批 5 個 |
| > 100 | 5+ 批 | 每批最多 8 個（每 agent 最多 20 項） |

## Agent 啟動指令模板

使用 Task 工具（subagent_type: general-purpose）啟動每個 agent，prompt 中包含：

```
你是 [Agent 角色名]，負責驗證以下項目。

【5 層查證 Checklist】
1. 事實查核：實體存在性、名稱拼寫、基本資訊正確性
2. 時效性 + 來源：當前狀態確認、重大變更、資料新鮮度、來源可信度評級
3. 交叉驗證 + 數據：3+ 獨立來源比對、數學計算正確性、單位一致性
4. 邏輯 + 隱藏錯誤：前後矛盾、因果關係、單位換算、貨幣混淆、時間錯位
5. 技術術語：禁止籠統描述（如「AI 技術」→ 需具體框架名+版本）、版本正確性、術語使用是否符合定義

【反模糊規則】（僅技術架構/白皮書章節嚴格執行，商業概述允許合理概括）
- ❌ 「AI 技術」「先進演算法」「雲端技術」
- ✅ 具體框架名 + 版本號 + 演算法類型 + 平台名

【位置標記】每個結果標記 `📍 第X章 > 第Y段` + 原文引用

目標文檔章節：Read [文檔路徑]（offset/limit 讀取指定章節）

待驗證項目：
1. [項目] - 📍 第X章 > 第Y段
2. [項目] - 📍 第X章 > 第Y段
...

要求：
- 每項至少 3 個獨立來源交叉驗證（因為不同搜尋引擎常引用同一底層來源，3 個來源增加命中獨立來源的機率）
- 結果用 Write 寫入 {輸出目錄}/agent-N-[type].md
- 最後只返回一行摘要
```
