# 替代查證策略與專業領域驗證

## 當直接查證失敗時的 5 種替代策略

### A. 迢迴驗證
- 查證相關人物（CEO、創辦人）是否存在
- 查證母公司/子公司
- 查證合作夥伴是否提及該實體
- 查證地址是否真實存在

### B. 時間線驗證
- 查證新聞報導時間線
- 查證融資/IPO 記錄
- 查證產品發布時間
- 建立事件時間軸確認邏輯

### C. 產業交叉驗證
- 產業報告是否提及
- 競爭對手是否提及
- 媒體報導是否提及
- 學術論文是否引用

### D. 社群驗證
- LinkedIn 員工人數與動態
- Glassdoor 員工評價
- Reddit/論壇討論
- GitHub/技術社群活躍度

### E. 語義分析
- 描述是否過於模糊（「可能」「據說」）
- 是否使用免責聲明
- 資料來源的來源（是否為二手資料）

## 專業領域額外驗證 Checklist

根據文檔類型自動套用：

### 產業研究報告
- [ ] 市場規模數據來源
- [ ] 市佔率計算方法
- [ ] 競爭格局描述準確性
- [ ] 產業趨勢推論合理性
- [ ] 報價與成本資訊

### 學術論文
- [ ] 引用文獻是否真實存在
- [ ] 研究方法是否合理
- [ ] 統計顯著性是否正確
- [ ] 結論是否過度推論

### 技術文檔
- [ ] API 端點是否存在
- [ ] 程式碼範例是否可執行
- [ ] 版本號是否正確
- [ ] 套件依賴是否最新
- [ ] 安全性考量是否完整

### 商業提案/企劃書
- [ ] 財務數據合理性
- [ ] ROI 計算正確性
- [ ] 市場分析可靠性
- [ ] 執行計畫可行性
