# 停機保險（dead-man）與踩坑總表

> dead-man（停機保險）：一支獨立在背景跑的小程式，不管你人在不在、session 有沒有當掉，時間到或事情做完就自動把結果拉回來、把機器關掉。
> **開機的同一個動作就要掛上，沒有例外，連 5 分鐘的小測試也一樣。**

## 1. 我們出過的三次事

| 日期 | 發生什麼 | 損失 | 學到 |
|---|---|---|---|
| 2026-08-12 | 任務跑完，AI 助理在等人回答問題，人不在；等待期間所有提醒都停了 | 空轉 2.3 小時 | 付費機器開著時，不要停下來等人回答；要問就先停機再問 |
| 2026-08-14 | 小測試跑完，腳本正常結束，但沒掛停機保險 | 空轉 6～7 小時，最後餘額用完被平台砍，**當晚的結果全沒了** | 小測試也要掛；結果每輪都拉回本機 |
| 2026-08-18 | 本機 WSL 重開機，背景的停機保險一起被殺 | 空轉約 6.7 小時 | 機器上也要掛一份 |

每次約 US$3～7，錢不多，但**結果丟失**才是最痛的。

之後（2026-10-06）改成三條保險同時掛。那趟從開機到評測跑完約 6.8 小時，跑完後 2 分鐘內送出停機並回查到 STOPPED。不過 adapter（LoRA 權重檔）走 ssh 拉回時中途斷線，後來改從 `/vault` 免開機抓回（見 02 第 5 節）。

## 2. 停機保險要有的東西

```
每 N 分鐘檢查一次：
  1. 先把小檔（log、進度、結果摘要）拉回本機     ← 機器下一秒被砍，數字還在
  2. 看有沒有這些情況，任一個成立就收工：
     a. 完成標記檔出現（例如 ALL_DONE）
     b. 失敗標記檔出現（例如 FAILED）
     c. 訓練程式出現過、之後又不見了，而且連續 20 分鐘都沒有（閒置）
        還沒出現過的話（還在裝環境、下載模型），改看「開機寬限期」，例如 90 分鐘
     d. 超過硬上限時數（例如 8 小時）
     e. 機器已經被外部停掉（要先看過它在跑；剛開機還沒起來時看到「已停」不算）
     f. ssh 連續好幾次連不上（當成失聯；連不上不能當成「訓練程式不見了」）
收工：
  0. 大檔在訓練腳本裡就先存到會保留的地方（gputw 的 /vault），不要留給停機保險做
  1. 小檔和結果包拉回本機，限時（例如 900 秒）
  2. 呼叫 API 停機；第 1 步超時的話，先送停機，再殺掉還沒拉完的程序
  3. 回查狀態，最多 20 次、每次隔 30 秒；第 3、10 次再補送一次停機
  4. 20 次都沒看到「已停」→ 留一個 ALERT 檔＋桌面通知
```

範本：`scripts/deadman_template.sh`（照上面的流程寫；開跑時會先檢查 id、時數是不是整數、API 找不找得到這台機器，任何一項不對就立刻報錯結束）

### 三條保險，互相獨立

一條保險會因為各種原因死掉（本機重開機、ssh 斷、機上程式當掉）。正式訓練掛三條，任何一條活著就停得掉：

| 哪一條 | 跑在哪 | 靠什麼停機 | 會死在哪 |
|---|---|---|---|
| 1. 本機停機保險 | 你的電腦 | ssh 看標記檔＋API 停機 | 本機重開機、網路斷 |
| 2. 機上看門狗 | GPU 機器上 | 機器自己呼叫 API 停機（沒附範本：照 `deadman_template.sh` 的判斷邏輯改成在機上跑，ssh 換成本機指令） | 機上程式被殺、機器當掉 |
| 3. 純時限保險 | 你的電腦 | 只打 API：時間到、還沒停就停（`scripts/gputw_api_backstop.sh`） | 本機重開機（但它不需要 ssh） |

目前只有 gputw 寫了第 3 條。RunPod 我們只掛過前兩條；要補第 3 條，照 `gputw_api_backstop.sh` 把查狀態和停機改成 `runpod_api.sh` 即可（未寫、未測）。

第 3 條最簡單也最可靠：不用 ssh、不管機上發生什麼，時間到就停。時間設成「預估總時數＋緩衝」。

### 停機那一步不能被別的事卡住

我們故意製造故障測過（2026-10-06）：收工時如果拉檔、寫 log 卡住，停機就永遠等不到。規則：

1. 拉檔放背景跑，設總期限（例如 900 秒）。
2. 期限一到，**先送停機**，再把還沒拉完的子程序殺掉、寫 log。
3. log 如果寫到網路硬碟或管線（pipe），寫入也要加逾時（例如 `timeout 3`）。log 寫到的地方卡住時，不能連帶卡住停機。範本的 log 寫到本機標準輸出，所以沒有加。
4. 停機保險裡所有 ssh／scp 都要加整體逾時。

### 小細節

- 用 `setsid nohup ... &` 丟背景，這樣 session 死了它還活著。
- 但本機重開機它一樣會死 → **機器上再跑一份**，用機器自己的 API 權限停機（token 用 stdin 傳進去，不要寫進檔案或 log）。
- 用 `pgrep -f` 找訓練程式時，寫成 `pgrep -f "[t]rain.py"`，避免找到 pgrep 自己。`pkill -f` 一樣要這樣寫；我們用 `pkill -f "sleep 3600"` 清理時，把自己的 shell 也殺了。
- 硬上限時數只吃整數。填 `2.5` 會讓 bash 算術出錯：有的寫法保險會直接結束，有的寫法保險照跑但硬上限永遠不會觸發，兩種都沒有明顯提示。所以範本開跑時就檢查是不是整數。
- 保險要寫 log 的資料夾必須先存在；不存在時 log 寫不進去，保險會無聲無息地死掉。發射後用 `pgrep` 確認它真的在跑。
- 每次發射都明確寫上硬上限，不要沿用別支腳本的預設值（我們曾經不小心繼承到 55 小時）。
- 訓練腳本本身用 `trap ERR` / `trap EXIT`，任何失敗都 `touch FAILED`（範本看的就是這個檔），停機保險才能提早收工。
- `set -e` + `pipefail` 的腳本裡，`ls | head` 在沒檔案時會讓整支腳本結束 → 用 `{ ls ... || true; }` 包起來。
- Colab 版：看標記檔用 `colab exec` 讀，連續 6 次 exec 失敗也當失聯收工。

## 3. 開機前檢查清單

- [ ] 餘額夠跑完整段嗎？（餘額不夠會被直接砍，不預警）
- [ ] 停機保險寫好了、硬上限時數設了嗎？（正式訓練：三條都掛）
- [ ] 有沒有另一個平台也在搶機？同一時間只准一邊訓練。
- [ ] 結果會存到哪？會保留的地方還是會消失的地方？
- [ ] 版本 lock 檔準備好了嗎？
- [ ] 判準（幾分算過）先寫下來了嗎？

## 4. 跨平台對照

| | Colab | gputw | RunPod |
|---|---|---|---|
| 開機 | `colab new` | API `restart`（第一台網頁建） | API `POST /pods` |
| 停機 | `colab stop` | `POST /instances/stop` | `POST /pods/<id>/stop` → `DELETE` |
| 回查 | `colab sessions` | `GET /instances` 看 STOPPED | `GET /pods/<id>` 看 404／EXITED |
| 停機後會留的地方 | 無（存 Drive 或下載） | `/vault` | 同一台的 `/workspace`（刪了就沒） |
| 停機後怎麼拿檔 | 沒存 Drive 就拿不到（停機前要拉完） | Vault API 免開機下載 | 重開同一台再拉 |
| 機上能自己停機嗎 | ❌（只能靠本機） | ✅（機上呼叫 API） | ✅（機上呼叫 API） |
| 傳檔 | `colab upload`（>100MB 要分塊） | tar over ssh（無 rsync） | scp／rsync／tar |
| 機內 poweroff 有用嗎 | — | ❌ | — |

## 5. 跨平台踩坑總表

| 坑 | 在哪遇到 | 解法 |
|---|---|---|
| 腳本正常結束，機器沒停 | 全部 | 停機保險的「閒置即停」 |
| API 說停了其實沒停 | gputw、RunPod | 一定回查 |
| 餘額用完直接砍機、資料全失 | gputw、RunPod | 開機前算預算；每輪拉回小檔 |
| `torch.cuda.is_available()` 是 True 但一算就炸 | Blackwell 卡 | `gpu_preflight.py` |
| pip 默默改掉 torch／transformers 版本 | 全部 | lock 檔 |
| transformers 版本不對，推論答案變差但不報錯 | vLLM + Gemma 4 | 版本雙鎖，開跑前檢查 |
| 存檔參數沒生效，被砍後 0 個 checkpoint | RunPod | 啟動時印出實際生效的參數 |
| 上傳大檔失敗 | Colab | 40MB 分塊 |
| ssh 吊住呼叫端 | gputw | `ssh -n -o BatchMode=yes`；長任務丟背景 |
| 掛牌價 ≠ 實付價 | gputw、RunPod | 看 API 回的實際時價 |
| 同一份 log 開好幾個監看，時間判讀錯亂 | 本機 | 重跑前先關掉舊的監看 |
| 停機前做快照／寫 log 卡住，停機一直沒送出 | 全部 | 先送停機，其他事放背景＋逾時 |
| ssh 拉大檔中途斷線，機器已停 | gputw | Vault API 免開機下載 |
| 兩個平台同時開機訓練，花兩份錢 | 同時搶 Colab＋gputw | 同一時間只准一邊；先通過 smoke 的留下 |
| 監看關鍵字誤觸 | 本機 | 看標記檔，或關鍵字帶上下文 |
