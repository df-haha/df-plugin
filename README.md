# Claude Plugins Marketplace

自訂 Claude Code plugins 集合。

## 安裝方式

```bash
claude plugin marketplace add df-haha/claude-plugins-marketplace
```

## 安裝 plugin

```bash
claude plugin install first-principles
```

## 可用 Plugins

| Plugin | 說明 |
|--------|------|
| **first-principles** | 第一性原理思考框架 — 基於 Elon Musk 的第一性原理方法論，自動拆解問題到最基本的事實與假設 |
| **markitdown** | 使用 Microsoft MarkItDown 將 PDF、PPT、Word、Excel 等檔案轉換為 Markdown |
| **dafon-doc-gen** | 大豐環保品牌文件生成工具 — 產生符合 CIS 規範的 PowerPoint 簡報與 Word 文件 |
| **deep-research-ryan** | 多層次深度研究引擎 — 自動調度 subagents 執行多階段研究，支援公司、產品、技術、產業、人物等 8 種研究類型 |
| **fact-check** | 文檔事實查核系統 — 5 層查證架構，支援實體、技術、數據、人物、論述的交叉驗證 |
| **daily-work-log** | 跨專案工作日誌產生器 — 掃描 Claude Code session + ccusage token 成本分析，產出 markdown 日誌並可透過 Outlook 寄出 |
